# 子 Agent 委派与模型选择

## 委派判断与前置检查

1. 自行判断是否需要委派子 Agent；可直接高效完成的简单任务不强行委派。
2. 仅在新建子 Agent 时执行模型选择流程；续用同一子 Agent 无需重新选模。
3. 新建子 Agent 前，先检查当前工具是否支持显式指定模型。若无法显式指定模型，告知用户并停止启动。

## 模型列出与确认

若用户尚未为本次子任务明确指定模型，在启动前完成以下步骤并等待用户明确选择：

1. 说明本次子任务内容与预期结果。
2. 查询当前可用的代理与模型，按提供方分组列出所有可显式指定的模型，逐项用行内代码显示工具返回的完整模型 ID。
3. 在清单中标记推荐项并简述理由。

## 启动、上下文与交接

- 启动新建子 Agent 时，显式传入用户所选模型的完整 ID；若该模型不可用，告知用户，不自动回退到其他模型。
- 仅传递子任务所需的必要上下文，并要求子 Agent 返回结果、关键依据和未确认项。
- 主 Agent 负责最终判断与向用户交接；委派不扩大权限，也不替代独立审查。
