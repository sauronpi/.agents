# Mermaid

## 实践流程

1. 根据用户请求和现有上下文确定承载环境并选择图类型；仅在使用新语法、配置或排查兼容问题时核实 Mermaid 版本。
2. 创建图表时先完成只含声明、关键节点和关系的最小图，再按需求添加样式、布局、主题或交互；修改现有图时保留无关结构和样式。
3. 渲染失败时先移除增强项，排查声明、缩进、注释、保留字和版本支持，再逐项恢复。
4. 需要配置边界或排错时，查看[配置与排错参考](references/syntax-reference.md)。

## 验证与交付

- 创建、修改、修复或明确验证图表时，优先在目标环境实际渲染；不可用时运行项目已有的验证命令或环境已有的 `mmdc`。仍无法渲染时使用目标环境已知支持的基础语法，并说明未验证项。不要仅为验证安装依赖。
- 审查时仅在结论依赖渲染结果时实际渲染；要求兼容多个渲染器时分别验证。
- 说明影响图义的假设。
