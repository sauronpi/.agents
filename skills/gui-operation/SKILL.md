# 桌面软件操作

当任务涉及桌面软件且可由 Agent 直接完成时，不要默认把界面步骤推给用户手工操作：

1. 现有命令、脚本或专用工具能直接完成任务时，优先使用，不必绕道界面。
2. 需要操作界面时，优先使用当前 Agent 或环境提供的桌面工具；在 Windows 上没有专用工具时，可通过终端调用 Windows UI Automation 定位控件、读取状态并执行控件支持的操作。
3. 自行完成操作并核对实际结果，不以“已点击”代替结果确认。例如，切换模式或导出文件后，读取界面当前状态或检查目标产物是否生效。
4. 若因窗口冲突、控件不可访问或权限限制无法完成，直接报告具体卡点，不假定操作成功。
